# LAST SIGNAL — COMPLETE EDITION

1000m × 1000mの区域で11人が生存を争う、オフライン一人称サバイバルシューティングです。主武器は現地調達。拳銃または投げ縄・地雷・トリップワイヤー・虎ばさみのいずれかを開始装備として選びます。

## すぐ遊ぶ

1. ZIPをすべて展開します。
2. ルートにある `index.html` をChromeで開きます。
3. 実戦は「区域へ降下」、武器の撃ち比べは「射撃訓練場」を押します。
4. PCではゲーム画面をクリックしてマウス視点を固定します。

インターネット接続やインストールは不要です。音声は最初のボタン操作後に有効になります。

## Androidで遊ぶ

- 横画面を推奨します。
- Chromeを推奨します。
- キーボード／マウス接続時は、操作設定の「自動判定」で動かない場合に「Android外付けマウス / Pointer Events」を選んでください。
- 画面端で旋回が止まる端末では「Androidマウス：端旋回」を有効にします。
- タッチ操作UIは「自動」「常に表示」「非表示」から選べます。
- タッチ操作限定の「ADS追尾補助」をON / OFFできます。試合中にマウスまたはキーボード入力が一度でも入ると、その試合では補助が無効になります。
- スマホ横画面では照準周辺を空け、右側の操作ボタンをマップ下の二段配置へ自動調整します。
- Pixel 7級を基準に、通常95m・ロングショットのスコープ時120mの描画距離に調整しています。

## ゲームルール

- 最大20分、敵10名＋プレイヤー1名。
- 後半10分は1分ごとに生存者の位置をマップへ表示。
- 最終1分は生存者の位置をリアルタイム表示。
- 通常武器19種＋回数無制限のフィールドナイフを収録。
- 銃には装弾数、予備弾、装填時間、初動、連射速度、精度、射程、弾速、弾道落下、発砲音、反動、取り回しに加え、簡易ADSの構え速度が設定されています。
- 右クリック（タッチUIはAIMボタン）で簡易ADSをON / OFF。武器画像が中央寄りへ移動し、構えが完成するほど精度と反動制御が向上する一方、移動速度と視点感度は低下します。
- 拳銃・SMGは素早く構え、ARは中間、LMG・狙撃系は重くゆっくり構える特性です。LONGSHOTのみ従来のスコープ表示へ移行します。
- BR-3は1回の入力で3発を連続発射する3点バーストです。
- 落ちている武器と手元の武器は同じ形状体系を使い、カテゴリーごとのシルエットで判別できます。
- 武器と副装備は透過画像で表示され、手元・フィールド取得物・武器一覧で同じ外観を共有します。
- ALPHA / BRAVO / CHARLIEの3集落では主武器と副装備を取得できます。
- NPCは視野内の相手だけを直接発見します。見失った地点、銃声、被弾方向、消えた物資マーカー、定刻シグナルからは不確かな位置を推測して警戒・捜索します。
- 非戦闘時の巡回は小範囲ランダム歩行だけでなく、ALPHA / BRAVO / CHARLIEを交通ノードとして数十〜100m単位で移動します。集落の混雑は少し避けるため、全NPCが同一点へ雪崩れ込む挙動は抑えています。
- 銃声への反応は個体差を持ち、好戦的なNPCは調査し、低HPまたは慎重傾向のNPCは離脱を選ぶ場合があります。消えた武器マーカーは「現在位置」ではなく、短時間だけ残る取得地点の痕跡として扱います。


## 射撃訓練場

- タイトル画面の「射撃訓練場」から直接入れます。
- 左レーンは静止標的、右レーンは横移動標的です。距離は10 / 25 / 50 / 75 / 100m。
- 標的は100HPで、撃破後約0.7秒で自動復帰します。
- 予備弾は無制限ですが、装弾数とリロード時間は実戦と同じなので継戦能力も比較できます。
- 画面右上のRANGE CONTROL、または `[` / `]` で全射撃武器を即時切替できます。
- `T` で標的、発射数、命中数、命中率、DOWN数をリセットします。
- 射撃場でも実戦と同じ簡易ADSが使えるため、腰だめと構え撃ちの精度・反動・取り回し差を比較できます。
- 射撃場ではNPC戦闘、信号公開、制限時間、ワールド境界ダメージは作動しません。

## ECHO MEMORY（NPC学習）

- 10体のNPCは、それぞれ別の内部個体として撃破・被弾・死亡・生存経験を保存します。
- 正面攻撃、側面移動、突撃、撤退、射撃位置維持などの成功度が個体別に変化します。
- NPC同士が同じ標的を攻撃して生存すると、相互の信頼・共闘価値が蓄積します。
- 関係の良い個体は一時的に攻撃を保留し、追従、挟撃、同一標的への攻撃を選ぶ場合があります。
- 終盤は共闘より個体の勝利を優先するため、固定チームではありません。
- 内部個体と画面上のECHO番号はマッチごとに入れ替わります。
- 学習は能力値の不正強化や位置透視ではなく、行動選択の成功確率だけを変化させます。
- 知覚条件は全個体共通で固定です。学習するのは、距離と鮮度が異なる情報を追うか、待つか、戦闘でどう動くかです。

学習研究画面を使う場合は、タイトルの「LAST SIGNAL」ロゴを3秒以内に5回タップし、管理コード `ALICE` を入力します。研究画面では全学習データのJSON出力と初期化ができます。通常画面に管理機能を示す表示はありません。

## ローカルサーバーで起動する場合

必須ではありません。Pythonが入っているPCでは、このフォルダーで次を実行して `http://localhost:8000/` を開けます。

```bash
python -m http.server 8000
```

## セーブについて

ゲーム進行はマッチ終了時に破棄されます。操作設定とECHO MEMORYの個体別学習記録はブラウザのローカルストレージへ保存されます。ブラウザデータを削除すると学習記録も消去されます。
