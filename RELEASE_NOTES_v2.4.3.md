# LAST SIGNAL v2.4.3 — MOBILE AIM REFINEMENT

- The temporary assist ON/OFF control is shown only while LONGSHOT scope is active, and is no longer displayed with ordinary AIM.
- Ordinary ADS target tracking is constrained to the normal-view draw distance (95m, with 8m margin). Scoped tracking respects the scoped-view draw distance (120m, with 3m margin).
- Pre-match tracking configuration and temporary override reset behavior are preserved.
- No weapon statistics, learning algorithms, enemy behaviors, or map rules were changed.
